# Fullsend Deck agent handoff

Before changing this workspace, read in order:

1. the repository-root `AGENTS.md`;
2. `docs/execution/README.md`;
3. `docs/execution/state.md`;
4. the assigned phase document; and
5. `docs/execution/contracts.md`.

Treat the locked decisions in those documents as requirements. Update
`docs/execution/state.md` at the end of every phase and leave later phases
unimplemented unless the active task explicitly includes them.
